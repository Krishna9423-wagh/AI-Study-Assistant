# RULES FOR THIS PROJECT

- Plain HTML, CSS, vanilla JavaScript only. No frameworks, no npm packages, no build tools.
- Keep files separate: `index.html`, `css/style.css`, and small JS files in `js/`.
- Never write an API key anywhere in code. The key is only read from `localStorage` (user pastes it in the Settings box).
- Every function must be small and have a short comment explaining it.
- Everything must work on phone, tablet and laptop, in both light and dark themes.
- Handle errors with clear user-facing messages, never silent failures.
- Don't rewrite files that don't need to change. Only edit what the task needs.
- After finishing, list exactly which files you changed.
